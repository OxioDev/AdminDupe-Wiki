Installation

  1. Télécharge le fichier .jar depuis Modrinth ou GitHub.
  2. Place-le dans le dossier plugins de ton serveur PaperMC.
  3. Lance le serveur pour générer config.yml et le dossier lang/.
  4. Arrête le serveur et configure les fichiers si nécessaire.
